Project 2: Travel Agency Website (Italy)
📝 Description

A travel agency landing page promoting guided tours and holiday packages across Italy. The page highlights packages and top itineraries using images and links.
🛠️ Concepts Used
Semantic HTML layout
Anchor links with target="_blank"
Figure & figcaption elements
Image accessibility with alt attributes

🎯 Learning Outcome

Structuring real-world webpages
Linking external resources
Using figures for visual content
